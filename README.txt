# IceHub Academy – Web Development Assignment

A multi-page educational website built with HTML, CSS (Flexbox + Grid), and responsive design.

## Pages
- `index.html` – Home page
- `about.html` – About page
- `courses.html` – Courses listing
- `contact.html` – Contact page with form

## Folder Structure
```
academy-website/
├── index.html
├── about.html
├── courses.html
├── contact.html
├── css/
│   └── style.css
├── images/
│   ├── banner.jpg
│   ├── webdev.jpg
│   ├── graphics.jpg
│   ├── data.jpg
│   └── others.jpg
└── README.txt
```

## Images Needed
Add the following images to the `/images/` folder:
- `banner.jpg` – Hero/banner image (recommended: 1200×500px)
- `webdev.jpg` – Web development related image
- `graphics.jpg` – Design/graphics related image
- `data.jpg` – Data/tech related image
- `others.jpg` – General academy/classroom image

## Features
- Responsive design (mobile, tablet, desktop)
- CSS Grid and Flexbox layouts
- Semantic HTML5 tags (header, nav, main, section, article, footer)
- External links to W3Schools, MDN, GitHub, freeCodeCamp
- Contact form with all required fields
- All images use appropriate alt attributes
- Rounded corners, shadows, hover effects
